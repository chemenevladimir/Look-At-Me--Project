# Установка Look At Me! на новый Windows‑ноутбук

Эта инструкция рассчитана на человека, который впервые видит проект. Для готовой сборки Node.js, npm и pnpm не нужны.

## 1. Установите необходимое

1. Установите **Google Chrome 116+**.
2. Установите **Python 3.10+ для Windows**. В официальном установщике желательно включить `Add python.exe to PATH`.
3. Подключите веб‑камеру и разрешите её использование в Windows: **Параметры → Конфиденциальность и безопасность → Камера**.

## 2. Распакуйте проект

Скачайте ZIP репозитория, выберите **Извлечь всё** и оставьте все файлы вместе. Путь и имя пользователя Windows могут быть любыми, включая кириллицу.

Не переносите отдельно только несколько JS‑файлов. Нужны вся папка `dist` и корневой установщик.

## 3. Загрузите расширение

1. Откройте в Chrome `chrome://extensions`.
2. Включите переключатель **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку `dist` внутри распакованного проекта.
5. Убедитесь, что появилась карточка **Look At Me!** без красных ошибок.

Chrome назначает unpacked‑расширению ID в зависимости от пути. Проект не содержит жёстко заданного ID.

## 4. Установите локальный helper

1. Закройте активную сессию Look At Me!, если она уже запущена.
2. Дважды щёлкните `INSTALL_WINDOWS.cmd` в корне проекта.
3. Дождитесь зелёного сообщения `Look At Me! local screenshot storage is ready`.
4. Нажмите любую клавишу, чтобы закрыть окно.
5. В `chrome://extensions` нажмите кнопку обновления на карточке Look At Me!.

Установщик автоматически:

- ищет ID расширения, загруженного из текущей папки `dist`;
- использует `py.exe` или `python.exe`;
- устанавливает bundled `keyboard==0.13.5` без интернета;
- копирует helper в `%LOCALAPPDATA%\LookAtMe\native-host`;
- создаёт manifest с найденным ID;
- регистрирует Native Messaging в HKCU, без прав администратора;
- показывает фактический путь к будущей базе и screenshots.

Если автоматическое определение нашло ноль или несколько копий, скопируйте 32‑символьный ID из карточки расширения и вставьте его в окно установщика. При переносе `dist` в другой каталог повторите этот шаг.

Если запуск `.cmd` запрещён политикой организации, откройте PowerShell в папке проекта и выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup_windows.ps1
```

## 5. Первый тест

1. Откройте `https://example.com` или тестовую Google Form.
2. Нажмите иконку Look At Me! в панели Chrome.
3. Дождитесь состояния `READY` и `Helper: READY`.
4. Введите имя студента и название теста.
5. Нажмите **Начать тест**.
6. При первом запуске откроется служебная вкладка Look At Me! Нажмите **Разрешить камеру и начать тест**, затем **Разрешить** в запросе Chrome. Вкладка закроется сама. Разрешение камеры для обычных сайтов не заменяет разрешение origin расширения.
7. Проверьте: Chrome вошёл в fullscreen, на странице появился overlay, popup показывает живую камеру.
8. Закройте popup кликом по странице. Overlay и камера должны продолжить работу.
9. Снова откройте popup: должна отображаться та же сессия `TESTING` с тем же score.

## 6. Завершение теста

1. Откройте popup.
2. Нажмите красную кнопку **Завершить тест**.
3. Подтвердите «Вы действительно хотите завершить тест?».
4. Дождитесь `FINISHING`, затем `COMPLETED`.

Штатный выход из fullscreen не начисляет баллы. В завершённом состоянии popup показывает имя final screenshot.

## 7. Где находятся результаты

Откройте системную папку **Документы**, затем `LookAtMe`:

```text
LookAtMe\
├── database.db
├── recordings\
└── screenshots\
    ├── image001.png
    └── final001.png
```

Путь определяется через Windows Known Folder и работает при любом имени пользователя и при перенаправлении Documents в OneDrive.

В popup нажмите **Открыть базу нарушений**. Страница должна показать `Helper: Online`, события, длительность, severity, score impact, session ID и имена PNG. Кнопка **Удалить** удаляет выбранное событие и его PNG после подтверждения.

## 8. Если Helper Offline

1. Не переустанавливайте всё расширение.
2. Запустите `INSTALL_WINDOWS.cmd` ещё раз.
3. Обновите расширение на `chrome://extensions`.
4. На странице базы нажмите **Подключить helper**.

Страница не должна бесконечно показывать загрузку. Offline — явное состояние. В фоне используется один reconnect‑таймер с паузой до 30 секунд.

## 9. Если камера не запускается

1. Закройте Zoom, Teams и приложения, которые могут удерживать камеру.
2. Проверьте Windows Camera Privacy.
3. В Chrome откройте `chrome://settings/content/camera`.
4. Обновите extension и повторите запуск на обычной HTTP(S) странице.
5. Запускайте тест кнопкой **Начать тест** в popup расширения. Если разрешение ещё не выдавалось, завершите одноразовый запрос в открывшейся служебной вкладке расширения.

Если запуск снова завершился ошибкой, popup показывает исходные `error.name`, `error.message`, состояние permission, число найденных video inputs и контекст вызова. Эти данные также выводятся в Console popup/offscreen с префиксом `[Look At Me]`.

## 10. Обновление или перенос

- После замены файлов `dist` нажмите **Обновить** на `chrome://extensions`.
- Обычная пересборка той же папки не требует переустановки helper.
- После загрузки `dist` из другого каталога Chrome может назначить новый ID — снова запустите `INSTALL_WINDOWS.cmd`.
- Старые данные в Documents не удаляются при обновлении.

## 11. Удаление helper

В PowerShell из проекта:

```powershell
.\native_host\uninstall_native_host.ps1
```

Сохранённые `database.db` и PNG остаются в Documents, пока пользователь не удалит их сам. Папку PNG можно открыть кнопкой **Доказательства** на странице базы. Каталог `recordings` создаётся автоматически, но видео в текущей версии не записывается.
