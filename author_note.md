Здравствуйте, уважаемые члены комиссии.

Для разработки данного проекта мы использовали Visual Studio Code и Codex от OpenAI в
 качестве инструмента для помощи в написании и отладке кода.

Основные технологии и компоненты проекта:

• База данных создана на Python с использованием SQLite.

• Детекция мобильного телефона реализована с использованием YOLOv8, согласно стеку технологий кейса №3.

• Детекция направления взгляда и наклона головы реализована с использованием MediaPipe Face Mesh.

• Браузерная часть проекта реализована в формате расширения
  для Chromium-браузеров с использованием JavaScript/TypeScript, HTML и CSS.
  
• Система событий фиксирует подозрительные действия пользователя
  и сохраняет информацию о них для последующего анализа.
  
• Для контроля действий пользователя и взаимодействия с операционной системой
  используются соответствующие программные инструменты Python.
  
• Интерфейс прокторинга отображает текущую активность,
  зарегистрированные события и состояние системы в реальном времени.
  
Codex использовался именно как инструмент разработки и помощи при решении технических задач.
Архитектура проекта, необходимые функции, тестирование и проверка работоспособности определялись
и выполнялись в процессе самостоятельной разработки проекта.

Вы можете просмотреть ROADMAP - то, как и по каким этапам разрабатывался проект.
Также, можете просмотреть AGENTS - то, по каким инструкциям действовал VSCode или Codex.
